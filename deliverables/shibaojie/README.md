# 食宝街门店最终交付包

这个目录是给客户直接下载的成品区，不需要再进 `data/` 目录找本地产物。

建议客户按这个顺序看：

1. `01_单店交付页.md`
   - 看整店当前交付状态和各平台数据链路
2. `02_实时舆情交付说明.md`
   - 看实时舆情系统怎么工作，以及为什么不是模糊的 “OpenClaw+skills”
3. `03_实时舆情看板.md`
   - 看当前命中的实时舆情内容和已过滤噪音
4. `04_系统使用说明.md`
   - 看客户日常怎么使用系统，以及如果继续沿用 OpenClaw 应该怎么配合
5. `05_实时舆情报告.txt`
   - 适合直接贴给飞书或运营同学
6. `06_给客户发送话术.md`
   - 直接复制给客户的发送文案
7. `07_口头介绍说明.md`
   - 开会或语音介绍时的标准讲法
8. `08_验收与结算说明.md`
   - 交付边界、公开验收口径和建议补确认项
9. `09_部署与运行说明.md`
   - 执行同学日常怎么跑、怎么导出客户版快照
10. `10_达人定向监控配置示例.md`
   - 重点达人名单、粉丝量门槛、认证类型和 POI 约束怎么配
11. `12_零技术门店KPI监管接入清单.md`
   - 给老板看的零技术说明，重点解释这套系统怎么做门店 KPI 监管
12. `13_一条命令验收跑通说明.md`
   - 给验收时看的最短路径说明
13. `14_客户运行包先看这里.md`
   - 如果客户拿到完整运行包，先看这份，不用先看代码
14. `15_老板只需要改这几个设置.md`
   - 老板如果坚持要自己改，实际只需要碰哪几个地方

如果客户只想下一份最核心的版本，优先下载：

- `01_单店交付页.md`
- `02_实时舆情交付说明.md`
- `03_实时舆情看板.md`
