# 鸿蒙端先看这里

## 先说结论

鸿蒙端这份包不是用来本机跑采集和控制台的。

当前第一版最稳的分工是：

1. `Windows` 电脑负责真正运行系统
2. `鸿蒙` 手机负责：
   - 看飞书消息
   - 提取飞书 webhook
   - 看验收结果
   - 配合首次登录和验证码

也就是说：

- `Windows 包` = 真正运行包
- `鸿蒙包` = 手机端协助包

## 鸿蒙端主要做什么

你在鸿蒙手机上，主要只做 4 件事：

1. 建飞书群、加机器人、把 webhook 发回来
2. 收系统推送过来的飞书消息
3. 看老板要看的结果文件
4. 某个平台首次登录或失效时，配合看验证码

## 鸿蒙端不需要做什么

你不需要在鸿蒙手机上：

- 安装 Python
- 安装运行环境
- 跑门店采集脚本
- 自己找会话文件
- 自己研究代码

## 最简单理解

把鸿蒙手机理解成：

- 老板查看结果的手机端
- 飞书接收端
- 首次部署时的协助端

把 Windows 电脑理解成：

- 真正跑系统的机器
- 保存登录状态的机器
- 负责半小时 / 一小时抓取的机器

## 你现在只要记住一句话

第一版不是鸿蒙本机跑系统，而是：

`Windows 负责运行，鸿蒙负责收消息和协助。`
