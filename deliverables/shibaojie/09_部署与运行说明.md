# 部署与运行说明

## 目录和角色

- 客户看结果：直接看 `01` 到 `04`
- 执行同学跑系统：主要用 `scripts/run_profile.sh`
- OpenClaw 如果保留：负责登录、抓取、调度和把原始内容写入标准输入文件

## 一键跑整店

```bash
cd /Users/wolaoposongwodediannao/Downloads/codex\ ai工作文件/group-buying-data-monitor
./scripts/run_profile.sh data/client_profiles/shibaojie
```

这条命令会更新：

- `single_store_deliverable.md`
- `signal_watchboard.md`
- `signal_report.txt`
- `signal_delivery_explainer.md`
- `client_usage_guide.md`

如果 `.env` 已配置 `GBM_FEISHU_WEBHOOK`，这条命令还会自动把运行摘要和实时舆情结果推到飞书。

## 飞书先怎么接通

1. 在仓库根目录复制 `.env.example` 到 `.env`
2. 填入 `GBM_FEISHU_WEBHOOK`
3. 如需在飞书里 @ 人，补 `GBM_FEISHU_AT_MOBILES`
4. 先跑一次测试命令：

```bash
cd /Users/wolaoposongwodediannao/Downloads/codex\ ai工作文件/group-buying-data-monitor
PYTHONPATH=src python3 -m gb_monitor.cli feishu-ping
```

这条命令成功后，再跑正式链路。

## 正式增量监控怎么跑

```bash
cd /Users/wolaoposongwodediannao/Downloads/codex\ ai工作文件/group-buying-data-monitor
PYTHONPATH=src python3 -m gb_monitor.cli profile-signals \
  --profile-dir data/client_profiles/shibaojie \
  --mode all \
  --notify \
  --mark-dispatched \
  --attribution-window-hours 2 \
  --board-output data/client_profiles/shibaojie/signal_watchboard.md \
  --report-output data/client_profiles/shibaojie/signal_report.txt
```

说明：

- `--mark-dispatched` 会更新去重账本，适合正式运行
- `--notify` 会把本次新增命中内容直接推到飞书
- `--attribution-window-hours 2` 表示发文后先观察 2 小时经营波动

## 给客户导出完整展示版怎么跑

```bash
cd /Users/wolaoposongwodediannao/Downloads/codex\ ai工作文件/group-buying-data-monitor
PYTHONPATH=src python3 -m gb_monitor.cli profile-signals \
  --profile-dir data/client_profiles/shibaojie \
  --mode all \
  --dedupe-hours 0 \
  --attribution-window-hours 2 \
  --board-output data/client_profiles/shibaojie/signal_watchboard.md \
  --report-output data/client_profiles/shibaojie/signal_report.txt
```

说明：

- 这条命令不会因为去重账本把当前命中内容隐藏掉
- 适合交付前导出“当前完整命中快照”
- 不建议用它替代正式增量运行

## 如果客户继续沿用 OpenClaw

推荐配合方式：

1. OpenClaw 登录目标平台并抓取原始内容
2. 把内容落进 `signal_inputs/public_xiaohongshu.json`、`public_douyin.json`、`public_shipinhao.json`
3. 由本系统做门店规则判断、噪音过滤、达人识别和看板生成
4. 客户只看最终交付文件，不看原始抓取结果

## 需要维护的关键文件

- `data/client_profiles/shibaojie/store_signal_rules.json`
  - 管门店规则、重点达人名单、粉丝量门槛、POI 约束
- `data/client_profiles/shibaojie/signal_inputs/*.json`
  - 管舆情原始输入
- `data/client_profiles/shibaojie/snapshots/*.json`
  - 管经营数据快照

## 常见调整

- 要盯固定达人：改 `focus_author_names`
- 要只看认证达人：改 `focus_verified_labels`
- 要只看一定粉丝量以上账号：改 `min_follower_count`
- 要强制内容带门店 POI：改 `require_poi`
- 要减少重复提醒：保持正式运行时带 `--mark-dispatched`

## 出问题先看什么

- 看 `execution_board.md`：确认平台登录和链路状态
- 看 `signal_watchboard.md`：确认有没有命中和为什么被过滤
- 看 `signal_report.txt`：确认运营文本是否可直接发送
- 看 `store_signal_rules.json`：确认规则有没有写得过松或过严
- 如果配置了 webhook 但飞书没收到，先重新跑 `PYTHONPATH=src python3 -m gb_monitor.cli feishu-ping`
