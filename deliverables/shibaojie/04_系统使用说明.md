# 凤状元·江西小炒·非遗米粉(食宝街店) 系统使用说明

- 城市：北京
- 适用对象：门店老板 / 运营 / 代运营 / 内部执行同学
- 核心原则：客户看到的是稳定的门店监测系统，不是直接操作底层采集脚本。

## 客户怎么理解这套系统

1. OpenClaw 可以继续保留，但它的角色是采集和执行引擎，不是最终交付本身。
2. 客户真正使用的是标准化后的结果层：门店指标快照、执行面板、舆情看板、舆情报告。
3. 这样做的好处是：以后即使换采集方式，客户使用方式也不用改。
4. 如果客户关心达人视频带来的引流，当前版本会给出“发布后经营波动观察”，但不会冒充精确归因。

## 客户日常使用顺序

1. 先看 `single_store_deliverable.md`，确认门店当前整体交付状态。
2. 再看 `execution_board.md`，确认哪个平台已打通、哪个平台还在补。
3. 看 `signal_watchboard.md` 和 `signal_report.txt`，确认实时舆情命中内容。
4. 需要查经营指标时，直接看最新导出的交付页或查询最新指标结果。

## 如果客户还是希望继续用 OpenClaw

可以，但要把职责说清楚：
- OpenClaw：负责登录、抓取、调度、把原始内容写进标准输入文件。
- 本系统：负责统一字段、门店规则判断、噪音过滤、去重、落库、出看板、出飞书文本。
- 客户最终看的是本系统产出的交付文件，而不是原始抓取结果。
- 如果要专盯重点达人，可以继续在规则里加作者级别、认证信息、粉丝量和 POI 门槛。

## 执行同学怎么跑

1. 先在 `.env` 里补 `GBM_FEISHU_WEBHOOK`；如果要飞书里 @ 人，再补 `GBM_FEISHU_AT_MOBILES`。
2. 先测试飞书机器人连通性：`PYTHONPATH=src python3 -m gb_monitor.cli feishu-ping`
3. 跑整店链路：`./scripts/run_profile.sh data/client_profiles/shibaojie`。如果 `.env` 已配置 webhook，这条命令会自动把运行摘要和实时舆情结果推到飞书。
4. 只跑实时舆情正式增量：`PYTHONPATH=src python3 -m gb_monitor.cli profile-signals --profile-dir 'data/client_profiles/shibaojie' --mode all --notify --mark-dispatched --attribution-window-hours 2 --board-output 'data/client_profiles/shibaojie/signal_watchboard.md' --report-output 'data/client_profiles/shibaojie/signal_report.txt'`
5. 导出客户展示版完整快照：`PYTHONPATH=src python3 -m gb_monitor.cli profile-signals --profile-dir 'data/client_profiles/shibaojie' --mode all --dedupe-hours 0 --attribution-window-hours 2 --board-output 'data/client_profiles/shibaojie/signal_watchboard.md' --report-output 'data/client_profiles/shibaojie/signal_report.txt'`
6. 生成舆情说明页：`PYTHONPATH=src python3 -m gb_monitor.cli profile-signal-deliverable --profile-dir 'data/client_profiles/shibaojie' --output 'data/client_profiles/shibaojie/signal_delivery_explainer.md'`
7. 生成客户使用说明：`PYTHONPATH=src python3 -m gb_monitor.cli profile-usage-guide --profile-dir 'data/client_profiles/shibaojie' --output 'data/client_profiles/shibaojie/client_usage_guide.md'`

## 重点达人怎么配置

- 打开 `data/client_profiles/shibaojie/store_signal_rules.json`。
- 常用字段：`focus_author_names`、`focus_author_tags`、`focus_verified_labels`、`author_level_include_keywords`、`min_follower_count`、`require_poi`。
- 推荐做法：合作达人放进重点名单；泛探店号用认证/粉丝量/POI 做门槛；招商加盟号继续放排除词。
- 给客户导出完整展示版时，不带 `--mark-dispatched`，并把 `--dedupe-hours` 设为 `0`。

## 需要客户补什么

- 登录验证码或二次验证时，按执行面板顺序一次性配合。
- 如果要接更多舆情来源，只需要继续补标准输入文件，不需要改客户使用方式。
- 如果要自动飞书推送，只需要补 webhook，不需要重做规则。
- 如果客户自己要跑，至少要拿到仓库代码、本地 profile 目录、Python 环境和飞书机器人 webhook。
