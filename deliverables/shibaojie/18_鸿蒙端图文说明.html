鸿蒙端协助说明

第一版不是让鸿蒙手机本机跑系统，而是让鸿蒙手机负责飞书接入、结果查看、验证码配合和验收确认。真正运行系统的机器，仍然是 Windows 电脑。

当前分工

Windows 运行
鸿蒙查看
飞书接收
验证码配合

这套分工的目的，是让第一版先稳定跑通，而不是把风险压到鸿蒙本机部署上。

鸿蒙端第一步

  1. 打开飞书
  2. 点底部“消息”
  3. 进入要收系统消息的那个群
  4. 打开群设置
  5. 找到“群机器人”
  6. 添加“自定义机器人”
  7. 把 webhook 地址发回来

鸿蒙端日常看什么

  • 飞书有没有收到测试消息
  • 飞书有没有收到正式监测结果
  • 哪个门店今天 KPI 未达标
  • 哪个平台当前需要补登录
  • 今日和昨日是否有变化

如果平台需要验证码

鸿蒙端不需要自己研究脚本，只需要看验证码并协助一次首次登录。后面会优先复用 Windows 电脑本地保存的登录状态。
