# 达人定向监控配置示例

## 这份配置解决什么问题

它解决的是客户之前提到的那个问题：

- 不是看到品牌词就推
- 不是 A / B / C 都推
- 而是只把真正和门店、探店、重点达人相关的内容推出来

## 推荐字段

- `focus_author_names`
  - 固定合作达人或重点账号名单
- `focus_author_tags`
  - 账号标签，例如“北京探店”“美食博主”“本地生活”
- `focus_verified_labels`
  - 认证类型，例如“探店达人”“美食创作者”
- `author_level_include_keywords`
  - 平台自己的等级口径，例如 `Lv.5`、`达人`
- `min_follower_count`
  - 最低粉丝量门槛
- `require_poi`
  - 是否强制要求内容带门店 POI
- `require_source_store`
  - 是否强制要求内容带门店来源直连字段
- `daily_target_count`
  - 该门店当天至少要完成多少条相关内容
- `store_aliases`
  - 门店别名，适合补门店简称、商圈简称、内部叫法

  "store_name": "凤状元·江西小炒·非遗米粉(食宝街店)",

  "include_keywords": ["凤状元", "江西小炒", "食宝街店"],
  "exact_include_keywords": ["凤状元·江西小炒·非遗米粉(食宝街店)"],
  "required_context_keywords": ["探店", "打卡", "美食", "团购"],

  "exclude_keywords": ["加盟", "招商", "培训", "招聘"],

  "focus_author_tags": ["北京探店", "美食博主", "本地生活"],
  "focus_verified_labels": ["探店达人", "美食创作者"],

## 推荐的三种打法

### 1. 固定合作达人

- 把达人昵称直接放进 `focus_author_names`
- 同时保留 `require_poi=true`
- 适合看固定合作探店内容

### 2. 泛达人精筛

- 不指定名单
- 用 `focus_verified_labels` + `min_follower_count`
- 适合看“所有有影响力的探店号”

### 3. 严格门店归属

- `require_poi=true`
- `required_location_keywords` 必须带商圈 / 城市 / 门店
- 适合把品牌噪音和异地内容压下去

### 4. 门店达标监控

- 给每个门店写 `daily_target_count`
- 如果能补 `source_store_id` / `source_store_name`，达标统计会更准
- 适合老板每天看各门店有没有完成内容发布任务

## 给客户的解释口径

现在不是“搜到关键词就推”，而是“门店词 + 场景词 + 位置词 + 达人条件 + 排除词 + 门店来源直连”一起判定。这样才能尽量做到客户要的“只推 C，不推 A/B”，并且还能看各门店当天到底发了多少条内容。
