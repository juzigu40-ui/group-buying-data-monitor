# 老板只需要改这几个设置

## 先说最重要的

如果你们没有技术同学，不建议自己研究代码和 PR。

最简单的使用方式就是：

1. 双击 `1_先双击安装.command`
2. 双击 `2_再双击打开控制台.command`
3. 在控制台里改设置并点运行

老板真正要改的，一般只有下面 4 类。

## 1. 飞书 webhook

打开控制台后，填这一项：

- `GBM_FEISHU_WEBHOOK`

作用：

- 系统把门店当天内容结果、KPI 状态、命中内容推到飞书群里。

## 2. 门店平台绑定

每个门店对应哪个平台账号、谁负责登录、是否启用，也已经放进控制台里了。

你们主要改的是：

- 接入方式：`manual / cookie / api`
- 账号标识
- 负责人
- 是否启用

## 3. 时间段和频率

如果你想改每天什么时间抓、多久抓一次，也是在控制台里改。

最常用的是这几项：

- `GBM_SIGNAL_WINDOW_START`
- `GBM_SIGNAL_WINDOW_END`
- `GBM_SIGNAL_INTERVAL_MINUTES`

例子：

- `10:00` 开始
- `22:00` 结束
- 每 `30` 分钟跑一次
- 每 `60` 分钟跑一次

外卖和评论监控也可以改：

- `GBM_REVIEW_WINDOW_START`
- `GBM_REVIEW_WINDOW_END`
- `GBM_REVIEW_INTERVAL_MINUTES`
- `GBM_DELIVERY_LUNCH_START`
- `GBM_DELIVERY_LUNCH_END`
- `GBM_DELIVERY_DINNER_START`
- `GBM_DELIVERY_DINNER_END`
- `GBM_DELIVERY_INTERVAL_MINUTES`

## 4. 每个门店的 KPI 目标

如果你想看“每个门店今天还差几条内容”，就在控制台里改每个门店的 `daily_target_count`。

它表示这个门店每天至少要完成多少条相关内容。

## 哪些不建议老板自己改

- 源码
- PR
- 数据库
- 原始抓取脚本
- 复杂门店规则

这些更适合由我们来维护。

## 最简单的理解方式

老板日常只需要：

1. 飞书里看结果
2. 需要改时间，就改控制台里的时间段和频率
3. 需要改门店账号，就改控制台里的平台绑定
4. 需要改门店目标，就改控制台里的 `daily_target_count`

其他技术细节，不需要老板自己处理。
