食宝街门店监测系统 - 先看这里

这是一个本地可部署的运行包，不需要先研究 PR、代码或命令行。

第一版先解决三件事：
1. 把登录后后台能看到的数据按门店跑起来
2. 把时间段、频率、门店绑定和 KPI 做成可视化可改
3. 把结果推到飞书

Windows 最简单的方式：
1. 直接双击：双击这里启动系统（Windows）.bat
2. 它会先把运行文件复制到 Windows 本机英文目录，再自动检查环境并打开控制台

如果你拿到的是旧版完整包，也可以按旧方式：
1. 双击 1_先双击安装.bat
2. 再双击 2_再双击打开控制台.bat

Mac:
1. 直接双击：双击这里启动系统（Mac）.command
2. 它会先把运行文件复制到 Mac 本机英文目录，再自动检查环境并打开控制台

打开控制台后：
1. 填飞书 webhook
2. 选每个门店的平台绑定信息
3. 改时间段和频率（30=每30分钟，60=每1小时，10=高峰期更密）
4. 改每个门店 KPI 目标
5. 点“测试飞书”
6. 点“运行验收”

登录这块第一版的原则是：
1. 只固定一台 Windows 电脑做部署和日常运行
2. 每个平台首次只登录一次
3. 后面优先复用这台电脑本地保存的登录状态
4. 客户不需要自己找会话文件
5. 如果平台失效，控制台会把它标成“需补登录”，再补一次验证码即可

你们验收时只看三件事：
1. 飞书有没有收到消息
2. 是否生成了结果文件
3. 看板里能不能看到每个门店当天数据和 KPI 状态

如果中间有报错，不需要自己分析，把报错页面截图发回来即可。
